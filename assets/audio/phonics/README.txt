FOLDER REKAMAN BUNYI PHONICS (bahasa Inggris)

Letakkan rekaman bunyi huruf di folder ini, satu berkas per huruf:
  a.mp3  b.mp3  c.mp3  ...  z.mp3
Format yang dikenali: .m4a, .mp3, .wav, .ogg, .aac
Nama berkas = huruf kecil (id huruf). Contoh: s.mp3 berisi bunyi /s/ ("sss"), BUKAN nama huruf "es".

Jika rekaman sebuah huruf belum ada, aplikasi memakai suara bawaan perangkat (perkiraan).
Rekaman yang ada otomatis dipakai menggantikannya. Hentikan lalu jalankan ulang aplikasi setelah menambah berkas.
